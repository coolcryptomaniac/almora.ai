# AETHERHOME Intelligence Agent

This directory powers the living R&D ledger at `journey.html`.

## Cadence
- Weekly: Sunday 12:00 IST — physical AI, robotics, autonomy, GPU economics, talent signals and roadmap implications.
- Monthly: first day of each month 12:15 IST — deeper program review and a Markdown report in `reports/`.

## Principles
- Public/source-linked inputs only.
- GitHub Models synthesis when available; deterministic fallback otherwise.
- Never invent vendor prices, salaries, funding, customers or technical readiness.
- Planning cost bands are hypotheses until replaced by real quotes.
- Every scheduled run is committed to Git, creating an auditable history from concept to delivery.
