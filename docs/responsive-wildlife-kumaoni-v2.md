# Responsive wildlife + Kumaoni rebuild

This branch removes the superseded `home-polish.css` and `local-info.js` layers, moves the responsive/theme/hero/live-info behavior into `experience.css` + `experience.js`, adds a mobile overlay sidebar, a responsive Aipan frame, a local AI-generated monkey illustration, a multilingual wildlife coexistence/reporting engine, and a Kumaoni learning page.

Safety: wildlife content is informational and routes reports to moderation; it does not order capture, relocation, sterilisation, hunting or killing. Legal details link current India Code/WII sources and avoid autonomous wildlife-management decisions.
