# Almora.ai — AI-Managed Remote Town Platform

Almora.ai is a town-scale AI platform for Almora, Uttarakhand, covering services, commerce, local intelligence, transport, tourism, governance and community problem-solving.

## AETHERHOME

The repository also contains the isolated AETHERHOME autonomous-living concept site under `/aetherhome/`. It includes an investor narrative, cinematic documentary simulations, a living R&D ledger and a scheduled physical-AI intelligence agent.

The AETHERHOME subproject is intentionally separated from the main Almora.ai application and does not replace the town platform.
